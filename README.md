# Git Learning · 版本管理入门
> 用一个小型仓库练习文件跟踪、提交与远程同步。

**Git · GitHub · 学习练习**

## 当前内容

仓库当前包含一个 [hello.txt](hello.txt) 示例文件，处于基础练习阶段。

## 仓库用途

用于观察文件修改、提交历史与 GitHub 远程仓库的关系。适合配合本地 Git 操作练习，不作为完整应用项目展示。

## 建议练习路线

1. 查看文件状态和修改差异。
2. 创建一次有明确含义的提交。
3. 在独立分支修改文件并比较差异。
4. 通过 Pull Request 练习变更说明与审阅。

以上是后续练习建议，未表示仓库已经包含对应示例。
